# سجل التغييرات — Field Report

## v5.0 (النسخة الختامية الأولى قبل التجربة الميدانية)

**التوافق:** قاعدة البيانات وصيغة ملف Excel لم تتغير (20 عموداً). التحديث فوق v4 يحافظ على البيانات لأن مفتاح التوقيع نفسه.

### جديد
- تصدير بخيارين: **تقرير اليوم** أو **كل السجلات**.
- اسم الملف المُصدَّر يحتوي رمز المشروع والتاريخ: `FieldReport_VL01_20261106_20261106_1530.xlsx`.
- شريط تنبيه في القائمة الرئيسية: عدد السجلات التي لم تُصدَّر منذ آخر تصدير، ووقت آخر تصدير.
- عرض رقم الإصدار في صفحة الإعدادات.
- أسماء واجهات الأدوار بالعربية (بدل Quantity / Issue / Material / Progress).

### إصلاحات
- تواريخ `Report_Date` تُقرأ صحيحاً عند استيراد ملف فُتح وحُفظ في Excel (كان Excel يحوّلها إلى رقم تسلسلي).
- رسالة التنبيه تظهر في كل مرة (كانت لا تظهر إذا تكررت نفس الرسالة، مثل حذف سجلين متتاليين).
- زر الرجوع في الجوال يعيدك للقائمة بدل إغلاق التطبيق.
- حذف ملفات التصدير القديمة (أكثر من يوم) من الذاكرة المؤقتة تلقائياً.
- التصدير لا يُنشئ ملفاً فارغاً: تظهر رسالة «لا توجد سجلات لتصديرها».
