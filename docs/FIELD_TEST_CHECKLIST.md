# قائمة اختبار v5.0 في الموقع

اختبر كل بند على جوال حقيقي، وسجّل (نجح / فشل) مع ملاحظة قصيرة. أرسل لي أي بند فشل مع لقطة شاشة.

## أ. التثبيت والبيانات
- [ ] تثبيت v5 فوق v4 يتم بدون حذف التطبيق، وتبقى السجلات القديمة.
- [ ] يظهر رقم الإصدار 5.0 في الإعدادات.
- [ ] على جوال جديد: شاشة الإعداد الأولي تظهر، ولا يمكن تجاوزها بدون الاسم والصفة ورمز المشروع.

## ب. الإدخال اليومي (لكل دور تستخدمه)
- [ ] اختيار الدور ثم البند، وإدخال الكمية، والحفظ. يظهر السجل في القائمة.
- [ ] حفظ سجل بدون كمية: تظهر رسالة، ولا يُحفظ.
- [ ] إضافة بند جديد من «+ إضافة بند جديد» ثم استخدامه.
- [ ] تغيير تاريخ التقرير وحفظ سجل بتاريخ سابق.
- [ ] حذف سجل: يطلب تأكيداً. حذف سجلين متتاليين: تظهر رسالة في المرتين.
- [ ] زر الرجوع في الجوال: من شاشة الدور يعود للقائمة، ومن الإعدادات يعود لما قبلها.

## ج. العمل بدون إنترنت
- [ ] وضع الطيران: الإدخال والحفظ والتصدير تعمل كلها.

## د. التصدير
- [ ] «تقرير اليوم»: يُنشأ ملف بسجلات اليوم فقط، ويفتح خيار المشاركة.
- [ ] «تقرير اليوم» بدون أي سجل لليوم: رسالة «لا توجد سجلات لتصديرها».
- [ ] «كل السجلات»: يحتوي كل السجلات.
- [ ] الإرسال عبر واتساب أو البريد يعمل، والملف يُفتح في Excel على الحاسوب.
- [ ] بعد التصدير يختفي تنبيه «سجلات لم تُصدَّر» من القائمة الرئيسية، ويعود بعد إدخال سجل جديد.

## هـ. الاستيراد
- [ ] استيراد قالب الإدارة (FieldReport_Template_v5.xlsx): تظهر المشاريع والبنود الجديدة.
- [ ] تصدير ملف، فتحه في Excel وحفظه، ثم استيراده: لا تتكرر السجلات، وتبقى التواريخ سليمة.

## و. بعد أسبوع من الاستخدام
- [ ] هل نسي أحد التصدير؟ (يدل على الحاجة لتذكير أقوى.)
- [ ] ما أكثر خطوة تُبطئ العمل؟
- [ ] ما الحقول الناقصة؟ (صورة؟ موقع GPS؟ تعديل السجل؟)
